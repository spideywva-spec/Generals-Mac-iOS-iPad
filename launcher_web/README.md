# Generals X launcher demo

Standalone visual prototype. It does not modify or execute the production UIKit launcher.

## Run

From the Generals-iPad workspace:

```powershell
.\launcher-demo\open-demo.ps1
```

Or open `launcher-demo\index.html` directly in a browser.

## Assets

- `assets/bg.png` — animated seamless tiled background.
- `assets/logo.png` — app/browser icon only; it is intentionally not shown inside the launcher UI.
